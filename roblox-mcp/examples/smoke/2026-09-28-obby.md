> **What it does**
> - **Stages:** the server builds the course when the game starts, so the place file needs no manual building. It has 5 green checkpoint pads that climb upward, and each of stages 1–4 has orange neon kill bricks (more on later stages).
> - **Checkpoints and kill bricks:** touching a kill brick, or falling off the course, kills the player. They respawn at their latest checkpoint. Stages only count in order, so skipping ahead does nothing.
> - **Leaderboard:** each player has a `Stage` stat, starting at 1.
> - **Timer:** it shows at the top centre as `M:SS.t`. It starts when the player first spawns on stage 1, keeps running through deaths, and freezes when they touch checkpoint 5.
> - **Tests:** they cover the stage rules, the timer maths and the course layout. The code that touches Roblox objects (kill bricks, respawn, on-screen timer) has no tests.
> 
> **Studio, in 5 lines**
> 1. Open Studio, create or open a place, and connect the Rojo plugin (run `rojo serve` in this folder). Or open `build/game.rbxl` directly.
> 2. Press Play. The course, leaderboard and timer come from the scripts.
> 3. Run to each green pad and check `Stage` goes up on the player list.
> 4. Touch an orange brick and confirm you respawn at your last pad, with the timer still running.
> 5. Reach pad 5 to confirm the timer freezes, then publish from Studio.
